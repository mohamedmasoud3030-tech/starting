# نظام إدارة عمليات الضيافة — Hospitality Operations

تطبيق ويب **عربي أولاً (RTL)** لإدارة عمليات الضيافة والمناسبات لمكاتب خدمات
الضيافة في **سلطنة عُمان** (أعراس، عزاء، مجالس، اجتماعات، وجبات، فعاليات).

**الهدف الوحيد للمنتج:** تحويل طلب العميل إلى مناسبة منفَّذة ومغلقة وربحية — من
تسجيل الطلب، عبر عرض السعر والتأكيد والتحضير، حتى الإغلاق وحساب الربح الفعلي.

**المستخدم الأساسي:** مالك المكتب (50+ عاماً) — البساطة متطلب منتج: خط كبير،
أزرار واضحة، أهداف لمس كبيرة، عربية أولاً.

**المبدأ المركزي:** المناسبة (Event) هي محور النظام، وكل ما هو تشغيلي يعود إليها.

## البدء السريع

```bash
npm ci                 # تثبيت التبعيات (Node 22؛ انظر .nvmrc / engines)
cp .env.example .env   # ثم ضع VITE_SUPABASE_URL و VITE_SUPABASE_ANON_KEY
npm run dev            # خادم تطوير على المنفذ 3000
```

متغيرات البيئة (أسماء فقط — بلا قيم): `VITE_SUPABASE_URL`، `VITE_SUPABASE_ANON_KEY`،
(أُزيل وضع العرض العام التجريبي نهائياً — الترحيل 0059).

قاعدة البيانات محلياً تتطلب Supabase CLI + Docker (الطريق الرسمي)، ويوجد طريق أصلي
تكميلي موثق في `PROJECT_COMMANDS.md` و`OPERATIONS.md`.

## التقنيات

React 19 + TypeScript (strict) · Vite 6 · TanStack Router/Query · Tailwind CSS v4 ·
PostgreSQL عبر Supabase (مخطط + RLS + أوامر RPC خادمية) · Supabase Auth ·
Vitest + Testing Library · pgTAP · oxlint. **لا يوجد خادم خلفي خاص** — قاعدة
البيانات هي مصدر الحقيقة وكل منطق الأعمال فيها.
