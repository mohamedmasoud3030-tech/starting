# 🍔 RestoPOS Pro - نظام كاشير وإدارة المطاعم الحديث

تطبيق ويب متطور لنقاط البيع (POS) وإدارة المطاعم والكافيهات، مبني بأحدث تقنيات الويب (React + Vite + Tailwind CSS + Lucide Icons) مع واجهة لمس عصرية ودعم كامل للغة العربية.

---

## 🌟 الميزات والمكونات الرئيسية

### 1. 💳 واجهة الكاشير ونقطة البيع (POS Register)
* **واجهة لمس تفاعلية:** بطاقات وجبات عصرية مع صور عالية الجودة، تصنيفات سريعة، وشارات مميزة (الأكثر مبيعاً، سبايسي 🌶️، جديد ⚡).
* **خيارات وتعديل الوجبات (Modifiers Modal):** اختيار الحجم (فردي، دبل، تربل)، الإضافات الإضافية (جبن، صوصات، بصل مكرمل)، وملاحظات خاصة للمطبخ.
* **أنواع الطلبات:** (سفري Takeaway / محلي Dine-in مع اختيار الطاولة / توصيل Delivery مع بيانات العميل).
* **سلة طلبات لحظية:** تعديل الكميات، حساب الخصومات السريعة (5%, 10%, 15%, 20%)، حساب ضريبة القيمة المضافة (VAT) تلقائياً، وتعليق الطلبات (Hold Orders).

### 2. 🖨️ شاشة الدفع وطباعة الفاتورة الحرارية (Thermal Receipt)
* دعم طرق الدفع المتعددة: **نقدي (Cash)** مع حاسبة فكة سريعة، **بطاقة بنكية (Mada / Visa)**، و **دفع إلكتروني (Apple Pay)**.
* **فاتورة ضريبية مبسطة:** متوافقة مع معايير الفوترة الإلكترونية ورمز الاستجابة السريع (QR Code)، مع إمكانية الطباعة المباشرة على طابعات الإيصالات الحرارية (80mm/58mm).

### 3. 🍳 شاشة المطبخ وإعداد الوجبات (Kitchen Display System - KDS)
* لوحة كانبان تفاعلية في الوقت الفعلي:
  * 🟡 طلبات جديدة معتمدة
  * 🔵 جاري الطهي والتحضير
  * 🟢 جاهز للتقديم والاستلام
  * ✅ أحدث الطلبات المسلمة
* عداد وقت لكل طلب مع تنبيهات لونية ورنة جرس المطبخ.

### 4. 🪑 إدارة الطاولات والصالة (Tables Floor Plan)
* عرض خريطة الطاولات حسب الأقسام (الصالة الرئيسية، كبائن العائلات VIP، التراس الخارجي).
* مؤشرات حالة الطاولة: 🟢 شاغرة، 🔴 مشغولة (مع قيمة الفاتورة ووقت الجلوس)، 🟡 محجوزة.
* فتح طلب جديد للطاولة بنقرة واحدة.

### 5. 📊 تقارير المبيعات وإغلاق الوردية (Z-Report)
* إجمالي المبيعات، عدد الطلبات، مبيعات الكاش مقابل الشبكة، ومتوسط قيمة الفاتورة.
* قائمة الأصناف الـ 5 الأكثر مبيعاً وإيراداً.
* سجل كامل لفواتير اليوم مع إمكانية البحث وإعادة طباعة أي إيصال.
* زر طباعة تقرير نهاية الوردية (Z-Report).

### 6. ⚙️ لوحة التخصيص وإدارة المنيو (Settings & Menu Management)
* **بيانات المطعم والفاتورة:** تعديل اسم المطعم، الفرع، الهاتف، العنوان، الرقم الضريبي، العملة (ر.ع / ر.س / $)، نسبة الضريبة %، ورسالة أسفل الفاتورة.
* **إدارة المنيو:** إضافة وجبات جديدة بالأسعار والصور والتصنيفات، وتعديل أو حذف الأصناف.
* **النسخ الاحتياطي:** تصدير واستيراد قاعدة البيانات كملف `JSON` وحفظ التغييرات تلقائياً في `LocalStorage`.

## 🚀 طريقة التشغيل والتثبيت

### المتطلبات:
* **Node.js** (إصدار 18 أو أحدث).

### خطوات التشغيل:
```bash
# الانتقال لمجلد المشروع
cd pos-app

# تثبيت الحزم (إذا لم تكن مثبتة)
npm install

# تشغيل خادم التطوير
npm run dev
```

### بناء نسخة الإنتاج (Production Build):
```bash
npm run build
```
سيتم إنشاء ملفات موقع الويب الثابتة الجاهزة للنشر داخل مجلد `dist/`.

## 🎨 هيكل المشروع (Project Structure)
```
pos-app/
├── index.html                  # الصفحة الرئيسية ودعم الخط العربي (Cairo)
├── package.json
├── vite.config.js              # إعدادات خادم Vite ودعم استضافة 0.0.0.0
└── src/
    ├── main.jsx
    ├── index.css               # استيراد Tailwind وتنسيقات الطباعة الحرارية @media print
    ├── App.jsx                 # المنسق الرئيسي للحالة وإدارة الطلبات
    ├── types/
    │   └── data.js             # البيانات الأولية للمنيو والطاولات والطلبات
    ├── utils/
    │   └── audio.js            # المؤثرات الصوتية (Web Audio API) بدون ملفات خارجية
    └── components/
        ├── Header.jsx          # الشريط العلوي والتنقل بين الشاشات
        ├── POSView.jsx         # شاشة الكاشير الرئيسية والبحث والتصنيفات
        ├── ProductCard.jsx     # بطاقة الوجبة
        ├── Cart.jsx            # سلة المشتريات وحساب الضرائب والخصومات
        ├── ModifierModal.jsx   # نافذة تخصيص الإضافات والأحجام
        ├── PaymentModal.jsx    # نافذة الدفع وحساب المبالغ النقدية
        ├── ThermalReceipt.jsx  # قالب الفاتورة الحرارية والـ QR Code
        ├── KitchenDisplay.jsx  # شاشة المطبخ (KDS)
        ├── TablesView.jsx      # خريطة إدارة الطاولات والصالة
        ├── ReportsView.jsx     # تقارير المبيعات وسجل الفواتير
        ├── SettingsView.jsx    # تخصيص بيانات المطعم والمنيو
        └── HoldOrdersModal.jsx # نافذة إدارة الطلبات المعلقة
```
