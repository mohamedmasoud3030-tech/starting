# 03 — النموذج التجاري

## الكتالوج

- `catalog_categories` — تصنيفات (اختيارية).
- `catalog_items` — الأصناف القابلة للتسعير، **منظّمة** بـ `organization_id`.

### أنواع الصنف (`item_type`)

`SERVICE`, `REUSABLE_EQUIPMENT`, `CONSUMABLE`, `STAFF`, `CATERING`, `TRANSPORT`,
`ADDON`, `OTHER`.

### طرق التسعير (`pricing_method`)

`FIXED`, `PER_EVENT`, `PER_GUEST`, `PER_UNIT`, `PER_HOUR`, `PER_DAY`, `MANUAL`.

### التكلفة مقابل البيع

كل صنف يحمل **قيمتين منفصلتين دائماً**:

| الحقل | المعنى |
| --- | --- |
| `cost_price` | ما يدفعه المكتب (تكلفة العمل) |
| `selling_price` | ما يدفعه العميل |

مثال: غداء مطعم — تكلفة `2.300` ر.ع./ضيف، بيع `2.800` ر.ع./ضيف. الفرق يساهم في الربح.

## الباقات (قوالب)

`packages` + `package_items` قوالب قابلة لإعادة الاستخدام (مثل «ضيافة قهوة — 100 ضيف»:
3 مضيفين + 1 مشرف + 4 دلال + 120 كوب + قهوة + تمر + بخور + ماء + طاولتان + أغطية).

- الباقة **قالب**؛ أسطرها تحمل كميات افتراضية فقط.
- عند إضافة الباقة لمناسبة، يمكن للمشغّل تعديل كل شيء (كميات، أسعار، حذف/إضافة أسطر).

## التسعير المرن للمناسبة (العقد المستقبلي)

يستطيع المالك تغيير سعر **أي شيء** داخل مناسبة معينة دون المساس بالكتالوج:

- تعديل سعر البيع وسعر التكلفة المتوقع لكل سطر.
- إضافة صنف مخصص، حذف سطر، تغيير الكمية، إضافة سطر يدوي، تعديل تفاوضي.

## اللقطات السعرية (Snapshot) — ثابت إلزامي

عند نسخ صنف/باقة إلى مناسبة، تُحفظ **لقطة** لكل سطر تجاري تتضمن:

- `source_catalog_item_id` (مرجع، وليس ارتباط حي)
- لقطة الوصف عربي/إنجليزي، الوحدة، طريقة التسعير
- الكمية، مضاعف الضيف، تكلفة الوحدة، سعر بيع الوحدة
- إجمالي التكلفة المتوقعة، إجمالي مبلغ البيع، الخصم/التعديل

**تغيير سعر الكتالوج غداً لا يغيّر أبداً عروضاً أو مناسبات قديمة.** لا يُعاد حساب
الاقتصاديات التاريخية من أسعار الكتالوج الحالية.

## اقتصاديات المناسبة (مستقبلاً)

- **الإيراد:** سعر بيع المناسبة + الإضافات + الأسطر المخصصة.
- **التكلفة المتوقعة:** تموين + طاقم + استهلاكيات + نقل + معدات + أخرى.
- **التكلفة الفعلية:** فواتير الموردين + تكاليف الطاقم الفعلية + الاستهلاك + الضرر/الفقد.
- **المخرجات:** الربح المتوقع، الربح الفعلي، المدفوع، رصيد العميل المستحق.

## ما نُفّذ في هذا الأساس

`catalog_categories`, `catalog_items`, `packages`, `package_items` مع قيود سلامة
مركّبة تمنع عبور المنظمات، وواجهة إدارة كتالوج كاملة (إنشاء/تعديل/تفعيل/تعطيل/أسعار).
