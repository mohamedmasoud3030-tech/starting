# 16 — الفواتير والتحصيل المعمّق (S6+)

## الغرض

S6 بنت طبقة التحصيل (دفتر دفعات العميل الثابت مقابل عرض سعر معتمد). لكن ما كان
ينقصها — حسب ما طلبه المالك — هو **كيان الفاتورة الرسمي** الذي يضم **العربون**
و**الدفعات المتعددة (الأقساط)**، مربوطاً بوضوح بعرض السعر والمناسبة، مع بقاء
السجل المالي غير قابل للعبث.

هذه الشريحة تضيف ذلك فوق S6 دون تكرار مصدر المال:

- `invoices` — فاتورة رسمية لكل مناسبة (رقم، تاريخ، القيمة الإجمالية، حالة).
- `invoice_installments` — جدول دفعات: عربون + أقساط + قسط أخير، كل بقيمة
  وتاريخ استحقاق.
- حالة «مدفوع» لكل قسط تُشتق من دفتر `customer_payments` (المحصَّل التراكمي مقابل
  المجدول التراكمي) — لا يوجد مبلغ مالي ثانٍ.

## مصادر الحقيقة

- القيمة المعتمدة: عرض السعر المعتمد (كما في S6).
- المحصَّل الفعلي: دفتر `customer_payments` (`RECORDED` فقط).
- المتبقي: `total_amount − المحصَّل`.
- جدول الدفعات: `invoice_installments` (الخطة المتفق عليها؛ ثابت بعد الإصدار).

لا يُنشأ أي دفتر أستاذ عام أو حسابات مدينة: الفاتورة هنا **أداة عرض وتحصيل**
مقابل المصادر القائمة.

## النموذج

### الأنواع

- `invoice_status` — `ISSUED`, `CANCELLED`.
- `invoice_installment_kind` — `DEPOSIT`, `INSTALLMENT`, `FINAL`.
- `installment_status` — `PENDING`, `PAID`, `CANCELLED`.

### الأوامر

- `create_event_invoice` — `OWNER`/`MANAGER`/`ACCOUNTANT`. ينشئ فاتورة من قيمة
  إجمالية + جدول دفعات؛ يجب أن **يساوي مجموع الدفعات القيمة الإجمالية تماماً
  (3 خانات)**، ويسمح بفاتورة واحدة صادرة لكل مناسبة.
- `void_invoice` — نفس الأدوار؛ إلغاء محروس يلغي كل دفعاتها.

## الأمان

- القراءة المالية محصورة على `can_read_cost` عند حدود البيانات.
- الكتابة عبر أوامر `SECURITY DEFINER` فقط؛ لا سياسة كتابة عميل.
- الجداول الخام غير ممنوحة؛ نماذج القراءة فقط الممنوحة.
- مشغّلات تمنع تعديل أي حقل مالي أو حذفاً تدميرياً؛ التحول المسموح `ISSUED →
  CANCELLED` (و`PENDING → CANCELLED` للدفعة).

## الواجهة

- تبويب **الفواتير** في مساحة عمل المناسبة: عرض الفاتورة (القيمة/المحصَّل/
  المتبقي) + جدول الدفعات مع حالة كل قسط (مدفوع/مستحق)، ونموذج إصدار فاتورة
  بالعربون والأقساط، وملخص صوتي (`buildInvoiceVoiceSummary`).
- التحصيل الفعلي يبقى في تبويب **المدفوعات** (S6)؛ هنا يُعرض فقط ربط الخطة
  بالمحصَّل.
