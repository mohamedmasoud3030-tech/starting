# 02 — دورة حياة المناسبة

المناسبة تمرّ بحالات صريحة مع انتقالات عمل محددة (وليس محرك سير عمل عام).

## الحالات

```
DRAFT       مسودة
→ QUOTED    تم إرسال عرض سعر
→ CONFIRMED تم التأكيد (مع دفع عربون)
→ PREPARING قيد التحضير (حجز معدات، إسناد طاقم، طلب تموين)
→ DISPATCHED تم إرسال المعدات/الطاقم
→ IN_PROGRESS المناسبة قائمة
→ RETURNING في طريق العودة (إرجاع المعدات)
→ CLOSED     مغلقة (تمت تسوية الحسابات)
CANCELLED    ملغاة
```

## قواعد الانتقال

- انتقالات الحالة **قواعد عمل صريحة**، وليست `status = "anything"`.
- كل انتقال **قابل للتدقيق** (auditable) عبر `audit_events`.
- `CLOSED` عملية مُتحكَّم بها بقائمة تحقق (انظر أدناه)، وليس `closed = true` عام.

## قائمة التحقق عند الإغلاق (مستقبلاً)

- المعدات أُرجعت؛ الأضرار/الفقد مسجّلة؛ المواد الاستهلاكية محتسبة.
- تكلفة المورد نهائية؛ تكلفة الطاقم نهائية؛ سعر العميل نهائي.
- المدفوعات مسجّلة؛ الرصيد المستحق معروف.
