# 06 — خارطة الطريق (شرائح التطوير)

## S0 — الأساس ✅

المصادقة، المنظمات، الأدوار، الكتالوج التجاري، قوالب الباقات، نظام التصميم، أساس RLS
والترحيلات والاختبارات، قشرة التطبيق العربية RTL.

## S1 — العملاء + أساس المناسبات ✅

العملاء، جدول `events`، دورة الحياة، مساحة عمل المناسبة.

## S2 — العرض السعري + التسعير المرن ✅

أسطر المناسبة، اللقطات السعرية، العرض السعري، التأكيد.

## S3 — جدولة الطاقم + حجز المعدات ✅

الإسنادات، فحوصات التداخل الزمني، وحجز سعة المعدات القابلة لإعادة الاستخدام.

## S4A — المعدات القابلة لإعادة الاستخدام ✅

الصرف، الإرجاع، التالف/المفقود، السعة القابلة للخدمة، التسوية النهائية، والتزامن
الحقيقي بين الحركات والتسوية والسعة المشتركة.

## S4B — المواد الاستهلاكية ✅

رصيد المواد الاستهلاكية كدفتر حركات append-only منفصل تماماً عن المعدات القابلة
للإرجاع: استلام، صرف للمناسبة، مرتجع صالح، استهلاك فعلي، هالك المناسبة، هالك
المخزن، تعديلات موثقة (رصيد افتتاحي/تصحيح جرد)، تسوية نهائية للمناسبة، منع
الرصيد السالب transactionally في قاعدة البيانات، والحد الأدنى/مؤشر النقص.
التفاصيل في [11-consumable-inventory.md](11-consumable-inventory.md).

**S4 مغلقة بالكامل (S4A + S4B).**

## S5 — الموردون + التموين ✅

المطاعم والموردون وطلبات التموين/الشراء، مع حفظ التكلفة التفاوضية لكل مناسبة وربط
الاستلام لاحقاً بحركات المواد الاستهلاكية دون إعادة تعريف مخزونها.
تكامل كامل للواجهة والخادم: إدارة الموردين، دورة حياة الطلبات (مسودة ← اعتماد ←
إرسال ← تأكيد ← استلام جزئي/كامل ← إلغاء)، الاستلام الفعلي وربطه بـ S4B، مساحة عمل
المشتريات، تبويب التوريدات في المناسبات، وعزل التكلفة حسب الصلاحيات.

**S5 مغلقة بالكامل (S5A + S5B + التكامل الإنتاجي).**

## S6 — المدفوعات + اقتصاديات المناسبة ✅

مدفوعات العملاء (تسجيل/إلغاء/سجل/طرق ومراجع)، معاملات مالية معرّفة
بالمعرّف، منع الدفعات غير الصالحة/المكرّرة، دقة OMR (ثلاث خانات)، رصيد
العميل، الإيراد المقبول كأساس موثّق للإيراد، تكامل تكلفة التموين (S5)،
وملخص اقتصاديات المناسبة (الإيراد المقبول/المدفوع/المتبقي/التكلفة الملتزم
بها والفعلية/الهامش الإجمالي) مع عزل مالي حسب الأدوار. التفاصيل في
[13-customer-payments.md](13-customer-payments.md).

**S6 مغلقة بالكامل.**

## S7 — لوحة تشغيلية + إشعارات ✅

لوحة يومية لمناسبات اليوم وحالة الجاهزية، تنبيهات تشغيلية من نقص الفريق/المعدات
ومؤشر المخزون المنخفض، مشاركة تذكير المناسبة عبر واتساب من بيانات التشغيل الحالية،
وتحسين PWA عبر manifest وService Worker آمن للكاش الثابت فقط. التفاصيل في
[14-operational-dashboard.md](14-operational-dashboard.md).

**S7 مغلقة بالكامل.**

## S8 — تصلّب الإنتاج ✅

إغلاق هندسي لجاهزية الإنتاج بدون ادعاء أن بيئة الإنتاج الحية قد تم تجهيزها:

- CI يعيد بناء قاعدة البيانات من الصفر ويشغّل pgTAP وعزل RLS واختبارات التزامن.
- اختبار آلي حقيقي ينفذ `pg_dump → reset → pg_restore → verification` على قاعدة
  Supabase محلية مع guard يمنع تشغيله على أي قاعدة بعيدة.
- نسخة الإنتاج من الواجهة تُبنى ثم تُشغّل كـpreview ويُفحص SPA routing وPWA
  والـService Worker وعقد النشر آليًا.
- تقسيم الصفحات إلى JavaScript chunks منفصلة، مع gate يمنع رجوع أكبر chunk فوق
  500 KiB.
- `vercel.json` يثبت SPA fallback وcache policy للأصول المhashّاة وsecurity headers.
- إجراءات النسخ/الاستعادة وUAT والنشر موثقة، مع فصل واضح بين الدليل الآلي وبين
  خطوات الإطلاق التي تحتاج مشروع Supabase/Vercel حقيقي ومشغل بشري.

التفاصيل وأدلة الإغلاق في
[`../operations/s8-production-closeout.md`](../operations/s8-production-closeout.md).

**S8 مغلقة هندسيًا. الإطلاق الحي يظل Launch Gate منفصلًا ولا يُعتبر منجزًا إلا بعد
ربط مشروع Hospitality حقيقي، تفعيل النسخ المدار، وإتمام الـhuman UAT/restore drill.**

## S9 — الحضور والأجور والفواتير المعمّقة ✅

الشريحة التشغيلية الأهم التي كانت ناقصة، وأجزاء من الـ Business-critical الثلاثة:

- **حضور المضيفين (Part 2):** سجل حضور/انصراف ثابت لكل إسناد مع ورديتين
  صباحي/مسائي، حساب الساعات والأجر (بالساعة/اليومية/المناسبة/يدوي) بدقة OMR
  ٣ خانات، والسلف والصرف مع أرشيف كامل لكل مضيف. التفاصيل في
  [15-staff-attendance.md](15-staff-attendance.md).
- **الفواتير والتحصيل المعمّق (Part 1):** كيان فاتورة رسمي يضم العربون والدفعات
  المتعددة (الأقساط) مربوط بعرض السعر والمناسبة، فوق طبقة التحصيل القائمة في S6.
  التفاصيل في [16-invoicing.md](16-invoicing.md).
- **مركز انتباه المالك (Part 3):** تجميع تنبيهات اليوم (جاهزية، مخزون منخفض،
  مناسبات لم يُسجَّل حضورها) مع زر صوتي للمالك. يبني على اللوحة التشغيلية S7.

**S9 مغلقة بالكامل.**
