# 06 — خارطة الطريق (شرائح التطوير)

## S0 — الأساس ✅

المصادقة، المنظمات، الأدوار، الكتالوج التجاري، قوالب الباقات، نظام التصميم، أساس RLS
والترحيلات والاختبارات، قشرة التطبيق العربية RTL.

## S1 — العملاء + أساس المناسبات ✅

العملاء، جدول `events`، دورة الحياة، مساحة عمل المناسبة.

## S2 — العرض السعري + التسعير المرن ✅

أسطر المناسبة، اللقطات السعرية، العرض السعري، التأكيد.

## S3 — جدولة الطاقم + حجز المعدات ✅

الإسنادات، فحوصات التداخل الزمني، وحجز سعة المعدات القابلة لإعادة الاستخدام.

## S4A — المعدات القابلة لإعادة الاستخدام ✅

الصرف، الإرجاع، التالف/المفقود، السعة القابلة للخدمة، التسوية النهائية، والتزامن
الحقيقي بين الحركات والتسوية والسعة المشتركة.

## S4B — المواد الاستهلاكية ✅

رصيد المواد الاستهلاكية كدفتر حركات append-only منفصل تماماً عن المعدات القابلة
للإرجاع: استلام، صرف للمناسبة، مرتجع صالح، استهلاك فعلي، هالك المناسبة، هالك
المخزن، تعديلات موثقة (رصيد افتتاحي/تصحيح جرد)، تسوية نهائية للمناسبة، منع
الرصيد السالب transactionally في قاعدة البيانات، والحد الأدنى/مؤشر النقص.
التفاصيل في [11-consumable-inventory.md](11-consumable-inventory.md).

**S4 مغلقة بالكامل (S4A + S4B).**

## S5 — الموردون + التموين — التالي

المطاعم والموردون وطلبات التموين/الشراء، مع حفظ التكلفة التفاوضية لكل مناسبة وربط
الاستلام لاحقاً بحركات المواد الاستهلاكية دون إعادة تعريف مخزونها.

## S6 — المدفوعات + اقتصاديات المناسبة

مدفوعات العملاء، المصروفات، الربحية المتوقعة/الفعلية.

## S7 — لوحة تشغيلية + إشعارات

مناسبات اليوم، تحذيرات، مشاركة واتساب، تحسين PWA.

## S8 — تصلّب التجربة

الأمن، التزامن، النسخ الاحتياطي/الاستعادة، UAT، جاهزية النشر.
