# اختبار يوم-1 مع مستخدم غريب — قائمة تحقق

الهدف: إثبات أن غريب يكمل المهمة بدون المؤسس.

## إعداد بيئة نظيفة (10 دقائق)
- [ ] أنشئ مشروع Supabase جديد (free tier)
- [ ] انسخ URL و anon key إلى `.env` من `.env.example`
- [ ] شغّل `npm ci && npx supabase db reset` (يطبق 102 هجرة + ينشئ bucket attachments عبر 0074)
- [ ] شغّل `npm run dev` → افتح `http://localhost:3000`
- [ ] تأكد من `supabase/config.toml` storage.enabled=true

## سيناريو المستخدم الغريب (بدون مساعدة)
1. [ ] افتح `/signup` → سجل بريد جديد + كلمة مرور 8+ أحرف
2. [ ] إذا طُلب تأكيد بريد، أكد (إذا confirmations=false، سيدخل مباشرة)
3. [ ] في Onboarding: أدخل اسم منشأة "مكتب الضيافة التجريبي" → إنشاء
4. [ ] اذهب إلى `/settings` → اضغط "تشغيل فحص النظام" → يجب أن يكون كله أخضر، اختبر رفع ملف
5. [ ] `/customers` → عميل جديد "شركة الاختبار" + جوال
6. [ ] `/catalog` → مادة "كرسي" نوع REUSABLE_EQUIPMENT، وحدة "قطعة"، سعر بيع 2.000، تكلفة 0.500
7. [ ] `/quotes/new` → املأ: عميل "شركة الاختبار"، عنوان "حفل زفاف"، تاريخ غداً، 100 ضيف، موقع "فندق X" → أضف "كرسي" كمية 50 → حفظ مسودة → إصدار → يجب أن يظهر رقم QT-YYYY-0001
8. [ ] افتح العرض → اعتماد → تحويل لمناسبة → يجب أن تذهب إلى `/events/$eventId` بحالة CONFIRMED
9. [ ] في المناسبة → تبويب الفريق → أسند نفسك أو عضو وهمي
10. [ ] تبويب المعدات → احجز 50 كرسي (capacity يجب أن تكون معرفة مسبقاً عبر EquipmentTab → سعة المعدات)
11. [ ] تبويب المدفوعات → تسجيل دفعة 100.000 نقداً → يجب أن يتغير المحصل/المتبقي في المالية
12. [ ] تبويب المالية → تسجيل مصروف نقل 20.000
13. [ ] ملخص → بدء التجهيز → تأكيد الإرسال → بدء التنفيذ → بدء العودة → إغلاق المناسبة → إغلاق مالي (إذا دورك OWNER)
14. [ ] `/reports` → يجب أن ترى المناسبة مع إيراد ومحصل ومتبقي وتكلفة وربح
15. [ ] `/accounting` → التقادم يظهر الذمم، كشف حساب العميل يظهر الدفعات
16. [ ] `/dashboard` → مؤشرات اليوم + تنبيهات

## معايير النجاح
- كل زر رئيسي يعمل بدون خطأ أحمر
- أرقام المستندات تتولد تلقائياً
- المحصل/المتبقي/الربح من DB وليس من UI
- لا تسريب بيانات بين منشأتين (جرب إنشاء منظمة ثانية وتبديل)
- المرفقات: سيلفي حضور يرفع ويظهر رابط موقع (signed URL)

## تسجيل
- سجل فيديو شاشة 5 دقائق من الخطوة 1 إلى 14
- احفظ لقطات شاشة للتقارير والمحاسبة

إذا فشل أي بند، سجله كـ P1 مع الملف والسطر.
